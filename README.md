# Javonn Liner apps and games

Static GitHub Pages portfolio for verified apps, web tools, games, policies,
support links, professional profiles, résumé, and current release status. The
approved repository is `javonn13/javonn13.github.io`, published at
`https://javonn13.github.io/`.

The 82nd 12th District Meeting privacy, support, privacy-request, and beta-status
page is published from `district-meeting-2027/`. Test binaries are distributed
privately and are not linked from the public site.

No build step is required. Publish the repository's `main` branch from `/`.
